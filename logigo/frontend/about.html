About LogiGo

LogiGo is a simplified logistics and transport management system built as a college project. It demonstrates a three-sided marketplace — customers who need goods moved, drivers who deliver them, and admins who coordinate the whole process — similar in spirit to real-world platforms like Porter.

This project is built with HTML/CSS/JavaScript on the frontend, Node.js + Express on the backend, and MySQL for data storage, and is designed to be deployable on AWS (EC2 for the app server, RDS for the database).
